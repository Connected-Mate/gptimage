GPTImage

You already pay for ChatGPT. Let your coding agent draw with it.

GPTImage plugs GPT Image 2 into Claude Code through your existing ChatGPT subscription. No API key. No per-image bill.

Set it up View on GitHub

The idea

Your Plus or Pro plan already includes image generation — but only inside the chat window, one picture at a time, copied out by hand. Meanwhile the image APIs want a credit card and charge per render.

GPTImage closes that gap. It signs in with the ChatGPT account you already have and hands the image model to your agent as a tool, so images land straight in your project as files.

Already paid for

Generation is billed to the plan you're already on. Nothing new to buy.

No API key

You sign in once in your own browser. The tool never sees your password.

Your agent drives

Claude Code writes the prompt, calls the tool, and saves the PNG where you need it.

Set it up once

You need Node.js 20 or newer and a ChatGPT account on an active plan.

git clone https://github.com/Connected-Mate/gptimage.git
cd gptimage
npm install
./install.sh

install.sh registers the tool with Claude Code globally, then opens your browser to Sign in with ChatGPT. When the success screen appears, you're done.

Because it's registered at the user level, it works in every Claude Code project on your machine. Restart Claude Code once so it picks up the new tool.

Then just ask

Open Claude Code in any project and describe what you want.

Generate a watercolor red fox in snow and save it to fox.png using the gptimage tool.

The agent expands your request into a proper prompt, calls generate_image, and writes the file. Existing files are auto-versioned — fox-v2.png, fox-v3.png — so nothing is ever overwritten.

Hand it reference images and it will restyle, combine, or edit from them:

Take the character in char.png and put them in the style of poster.png. Save it to hero.png.

Or from the terminal

npm run gen -- --prompt "a red fox in snow, watercolor" \
  --out fox.png --size 1024x1024

# with reference images
npm run gen -- -p "apply Image 1's style to Image 2" -o out.png \
  --ref style.png --ref subject.png

Sizes are auto or WIDTHxHEIGHT in multiples of 16 — square 1024x1024 for icons and avatars, 1536x1024 for banners, 1024x1536 for posters.

How it works

  1. You sign in with ChatGPT through the standard OAuth flow. The token is stored locally in ~/.gptimage/auth.json and refreshed automatically. Already logged into the Codex CLI? It reuses those credentials.
  2. A local MCP server exposes two tools to Claude Code: generate_image and image_auth_status.
  3. A skill (/gptimage) teaches the agent when to reach for image generation and how to write a strong prompt for it.
  4. The request goes to GPT Image 2 on your subscription, streams back as base64, and is saved to disk as a PNG.

Handy commands

CommandWhat it does
npm run statusShow your plan, account, and token expiry
npm run loginSign in again
npm run logoutRemove stored credentials
npm run genGenerate an image from the terminal

If Claude Code can't see the tool, restart it and check that claude mcp list shows gptimage ✔ Connected. A 429 means your plan hit its rate limit — wait and retry.

Before you start

This is a grey area, by design. "Sign in with ChatGPT" is officially meant for Codex. GPTImage reuses that token to reach GPT Image 2. It works and it's widely done, but it is not an officially sanctioned API.

Keep usage personal and local. Heavy use can trigger plan rate limits or, in the worst case, account restrictions. You accept that risk by using this. Not affiliated with OpenAI — use at your own risk, in accordance with OpenAI's terms.
